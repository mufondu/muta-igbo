# Mụta Igbo — Bug-Bounty & QA Report
**Date:** 29 July 2026 · **Mode:** Find + fix as I go · **Focus areas:** crashes, kid-safety & privacy, game/scoring logic, data integrity, vocabulary grounding

---

## 1. Fixed immediately (clear-cut)

### Kid-safety & privacy
- **"Say It Back" was secretly recording your child's voice.** It called the device recorder (`Audio.Recording`, high quality) and stored/played back the audio — directly contradicting the app's own privacy policy ("does not record, store, or transmit user audio") and with **no microphone permission even declared**. For an app for ~4-year-olds this is the single most serious finding. **Fix:** rebuilt it as a no-microphone *listen-and-repeat* activity — the child hears the word, taps "Now say it out loud!", gets praise, and moves on. All recording code is gone; no mic permission is needed.
- **Parent gate was too easy to guess.** The "grown-ups only" screen showed four tappable answers, so a child tapping randomly got through roughly 1 in 4 tries. **Fix:** the answer must now be **typed** on a number pad (no visible options), with a 3-try limit and a 15-second lock-out after that.

### Crashes & data integrity
- **Onboarding created malformed profiles** (wrong date formats, a fabricated goal count, and phantom fields forced in with a type cast) — a mismatch that could corrupt streak/goal logic. **Fix:** onboarding now uses the app's single canonical profile builder.
- **Old saved profiles could crash on load** if they were missing newer fields. **Fix:** loading now backfills every expected field with safe defaults.
- **Opening a level with an unknown id would crash** (non-null assertions). **Fix:** safe fallbacks added.
- **Opening any level reset its progress to a flat 10%.** **Fix:** progress now reflects how far through the level's sections the child actually is.

### Game logic
- **Word Search could be "won" with random filler letters**, not the real word. **Fix:** only the actual target letters count.
- **Word Match could collapse duplicate tiles** (e.g. the letter "a" and the vowel "a"), breaking a round. **Fix:** tiles are de-duplicated.
- **Picture Match could flash "complete" with zero items loaded.** **Fix:** guarded.
- **Two games weren't told about premium access** (empty pools possible). **Fix:** access now passed through.

*Verification:* every edited file was syntax-checked with the project's own TypeScript compiler (transpile mode, which — unlike a full type-check — runs to completion in this environment); brace/paren balance re-checked; game pools confirmed to still populate.

## 2. Second pass — the flagged items, now fixed

After the first pass I flagged six items for sign-off. You said "take on all," so I've since fixed five of them; the sixth stays with you by design.

1. **"Words learned" counter inflated — FIXED.** Every correct quiz answer used to add 1, counting the same word many times. Profiles now track a set of distinct words answered correctly, so the count is truthful. Existing profiles keep their current number (no jarring reset) and dedupe from here on.
2. **Word Match & Word Search always gave 3 stars — FIXED.** Wrong matches now subtract points in Word Match, and a mistake in a Word Search round earns half credit — so stars actually reflect how the child did.
3. **Streak daylight-saving off-by-one — FIXED.** "Yesterday" is now computed by calendar day instead of subtracting a fixed 24 hours, so DST transition days no longer break a streak early.
4. **Game timers not cleared on exit — FIXED.** Each game's round-advance timer is now tracked and cancelled if the child leaves mid-delay, so the app never tries to update a screen that's gone (no leak, no stray state warning).
5. **Free-tier quiz pool could be empty — FIXED.** `buildQuizPool` now has a safety net: if a tier filter ever empties the pool (e.g. switching from the current everything-unlocked beta to paid), it falls back to every quiz-able word so the quiz can never crash on an empty list.

**Still with you:**

6. **Vocabulary vs. dictionary differences** (from the earlier uploaded IgboGuide dictionary, which uses old Onitsha spelling) — left for a native speaker rather than auto-rewritten, per your "no unverified vocabulary" rule.

## 3. New feature — Pronunciation

Built from your **A1** and **A2** word lists (Wordmastery.org). These give English "say-it-like-this" respellings, e.g. *Ndewo → n-deh-woh*.

- **Existing words enriched:** 40 of the app's current words now show a pronunciation line, matched to your lists. I did **not** invent respellings for the rest — that would be unverified.
- **New "Everyday Phrasebook" level** (🗣️) with four kid-safe sections — Happy Feelings, Kind & Everyday Words, Time Words, and "I Can Do It!" (~23 phrases). Each has a pronunciation guide.
- **Kid-safety filter applied:** most of the A2 list is adult content — *bank, price, "my job is hard", vote, doctor, headache/fever*. Per your "strictly for kids" rule I left all of that out and used only the child-appropriate subset.
- **Display:** the guide shows always-visible, in a soft italic "🔊 …" line directly under each Igbo word (great for a parent reading along), on lesson cards, number cards, and the Say It Back screen.

> These new phrases are marked *unverified* (grounded in the Wordmastery lists, pending a native-speaker check) — consistent with how the app already flags un-reviewed vocabulary.

- **Home-screen icon fixed.** The new Phrasebook card was showing the word "Phrasebook" as pink placeholder text instead of a picture like the other level cards. It now uses the speech-bubble artwork (the closest kid-friendly match already in the app), so all cards look consistent.
